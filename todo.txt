 1. STUDY-SESSION UX FIX (S17)                                   (ES) [L]
    Problem (user testing 2026-10-30): "x / 4" counts cards in the
    session, but mastery is a hidden 0-5 score per card (Again->0, Hard
    +0, Good +1, Easy +2). All-Easy shows "0 newly mastered, 0%", a card
    retires only on its 3rd Easy, and "Again" silently grows the total
    (2/4 -> 3/5). It reads as broken.
 [x] Design picked 2026-10-30 (S19):
       a. Mastery dots: keep the 4 ratings, the 4-way swipe, and the FR-18
          rule. The card shows 5 mastery dots (StudyCardView). After a
          rating the dots fill or empty, with a short "+1" / "+2" / "Reset"
          / "No change" label (fade; a crossfade under Reduce Motion). The
          VoiceOver value is "Mastery n of 5".
       b. "Again" repeat (user's main complaint: "why answer 5 when it says
          x / 4"): the card still comes back once at the end, but it is
          announced the moment "Again" is tapped. The counter becomes
          "2 / 4 · +1 repeat" (VoiceOver: "Card 2 of 4, 1 repeat added"),
          and the bar tracks distinct cards (full while repeats play),
          so it never jumps backwards. The repeated card shows a "Repeat" chip, and
          the counter reads "Repeat 1 of 1" while repeats play. StudyQueue
          gains distinctTotal, repeatCount, and isRepeat(current).
       c. Summary tiles: Cards reviewed · Moved up (cards whose score rose
          this session) · Deck progress % = sum(masteryScore) /
          (5 x cards), with the delta in points. Show the "Mastered" line
          only when > 0. Add FlashcardDeck.progressRate. The deck tile and
          deck detail use it too, so the numbers agree; masteryRate stays
          for "mastered" counts and starter retirement. The snapshot stores
          the start progress and the moved-up IDs (new SwiftData fields:
          check whether they need a V8 schema, or reuse
          StudyProgressSnapshot fields).
       Built as: "Cards reviewed" counts distinct cards, with "· +n repeat"
       under it (a 4-card run with one Again says 4, not 5). New
       CodeySchemaV8 (StudyProgressSnapshot drops newlyMastered/
       startMasteryRate, adds startScores + startProgressRate), V7->V8
       lightweight stage. New MasteryDots component. Deck tile, deck
       detail, Home and Continue now say "progress" and n/distinct.
 [x] Implement a-c.
 [x] Tests: StudyQueueTests, StudySessionViewModelTests (incl. snapshot
     saved to the store), FlashcardMasteryTests (progressRate),
     MigrationTests (V7 -> V8); StudySessionUITests updated to the new
     counter. 342 unit tests pass; lint OK.
 [x] Bug found by the UI test and fixed: StudySessionView built its view
